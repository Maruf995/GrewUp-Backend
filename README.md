# 🚀 GrewUp-backend

Backend проекта **GrewUp**. Чистый backend‑проект на Django с использованием **SQLite** в качестве базы данных. Подходит для быстрого локального запуска без дополнительной настройки БД.

## 🧩 Требования

Перед началом убедитесь, что у вас установлены:

* Python **3.9+**
* pip
* Git

---

## 📥 Клонирование проекта

```bash
git clone https://github.com/maruf995/GrewUp-backend.git
cd GrewUp-backend
```

## 📦 Установка зависимостей

### 1. Создание виртуального окружения

```bash
python -m venv venv
```

Активация виртуального окружения:

* **Linux / macOS**

```bash
source venv/bin/activate
```

* **Windows**

```bash
venv\\Scripts\\activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 🗄️ База данных (SQLite)

Проект использует **SQLite** по умолчанию, дополнительная настройка базы данных не требуется.

Для создания базы данных и применения миграций выполните:

```bash
python manage.py migrate
```

После этого файл базы данных `db.sqlite3` будет автоматически создан в корне проекта.

---


## ▶️ Запуск проекта (пошагово)

Следуйте шагам строго по порядку.

### Шаг 1. Применение миграций

Создаёт таблицы в базе данных SQLite:

```bash
python manage.py migrate
```

---

### Шаг 2. Создание администратора

Создайте суперпользователя для доступа к админ-панели:

```bash
python manage.py createsuperuser
```

После создания админ-панель будет доступна по адресу:

```
http://127.0.0.1:8000/admin/
```

---

### Шаг 3. Запуск сервера

Запустите сервер разработки:

```bash
python manage.py runserver
```

Проект будет доступен по адресу:

```
http://127.0.0.1:8000
```

## 📡 Swagger / API документация

Если в проекте подключён Swagger (drf‑yasg или аналог):

* Swagger UI:

```
http://127.0.0.1:8000/swagger/
```

* ReDoc:

```
http://127.0.0.1:8000/redoc/
```

Через Swagger можно:

* просматривать все эндпоинты
* тестировать API
* видеть схемы запросов и ответов
